On-screen: The generated Citations Table. Each row is one extracted requirement with: ID, source section (e.g., L.3.2), the requirement text, a colour-coded type pill (Shall, Will, Should, May), a confidence-score bar coloured by value (green ≥ 95%, lime 80–94%, amber 60–79%, orange 40–59%, red < 40%), and inline citation links to the source text. Any requirement the system flagged for review shows a tiered flag beneath its text: Critical for validated contradictions (R-005), Important for ambiguity on high-impact clauses (R-004), Minor for non-contradictory vagueness (R-003). Search plus Type, Section, and Review filters narrow the list. Clicking a citation link opens the Citation Drawer (Overlay B); Export ▼ opens the Export Modal; Next → advances to the Questions Form.
